      MOVIE HUB — Indexing Tools

      This site is one single HTML file, so it cannot ship a physical sitemap.xml / robots.txt. Copy each block below and paste it where your host expects it: Blogger → Settings → Advanced (custom robots.txt) and submit the sitemap URL / paste the XML into an online sitemap host, then add it in Search Console → Sitemaps. Every page is already linked inside the page itself (footer, category tiles, poster links and #/sitemap), so Google discovers them automatically.

      Checklist

      1. Paste your Search Console domain-verification code into #gscVerification in the <head>.
      2. Publish the site at a real https URL (file:// can never be indexed).
      3. Submit the sitemap, then use “URL Inspection → Request Indexing” on the home page and on each category page.
      4. Re-submit after adding categories — the list above is generated from the live TMDB genre lists.

      Running from local file — Trailers blocked

      YouTube requires a valid HTTP referrer. Opening via file:// causes Error 153. Run a local server to fix this:

      npx http-server -p 8000

      Then open http://localhost:8000/moviehub.html
